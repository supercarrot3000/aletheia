# First agent reuse trial

An independent agent was given the checkout path and a library problem. It started at the README and located the findings page, catalogue and formal theorem in three shell commands.

- **Reuse.** If copies are grouped by title, equality of title survives a change of representative within each group.
- **Withhold.** If the groups have no acquisition-date constraint, a title group can contain January and February acquisitions. Against a group represented by a January acquisition, switching representatives changes whether the dates differ.
- **Scope.** The theorem establishes which relations survive grouping. A claim about a reader's experience requires other evidence.

The agent correctly declined to cite a clean commit for files that were still being edited. This is one repository-guided feasibility trial. The questions about public discovery and effort saved require separate trials. The formal theorem and examples were replayed by the maintainer as part of the integration review. A first-time human handoff with the worksheet remains to be observed.
